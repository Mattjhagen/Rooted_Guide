## UI Integration

Attribution placement is recommended in:

1. **Settings → About → Bible Translation** (concise version)
2. **Settings → About → Legal Information** (detailed version)
3. **Citation Detail View** (inline: "WEB • eBible.org")

The concise attribution provides transparency about the translation source while the detailed version satisfies recommended attribution practices.

---

## Trademark Compliance

"World English Bible" and "WEB" are trademarks of eBible.org. These names may be used to refer to the translation, but not to misrepresent modified versions as the authoritative WEB.

Plumb Line removes USFM formatting markup (Strong's numbers, footnotes, cross-references) but preserves the actual verse wording. This is considered formatting, not textual modification, and the translation may still be called "World English Bible."
